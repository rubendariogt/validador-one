# Validador RIPS en Python
Desarrollador: Rubén Darío García Tovar - Ingeniero de Sistemas

Proyecto basado en 15 años de experiencia creando el aplicativo RIPS en Dirección de Sanidad - Hospital Central (implantado a nivel nacional).

### ¿Qué hace?
Automatiza la validación de archivos RIPS (AF, US, AC, AP) antes del cargue a la plataforma.

### Tecnologías
- Python 3
- CSV handling
- Lógica migrada desde ASP.NET / Oracle

### Próximas mejoras
- Conexión directa a Oracle con cx_Oracle
- API REST con Flask
- Dashboard de errores
